- [ ] **Форма → Telegram + Sheets.** Код воркера: `site/worker/` (honeypot,

  1. Артём: создать бота у @BotFather → токен; узнать chat_id (бот @userinfobot).
  2. Артём: создать Google-таблицу «Заявки GruzMarket», сервис-аккаунт в
     Google Cloud Console, выдать ему доступ редактора к таблице.
  3. Артём: Cloudflare аккаунт → `cd worker && npx wrangler deploy` +
     4× `wrangler secret put` (команды в шапке wrangler.toml).
  4. Ассистент: прописать URL воркера в `PUBLIC_LEAD_ENDPOINT` (env сборки).
  До этого форма работает через WhatsApp-фолбэк (уже живая, не заглушка).
