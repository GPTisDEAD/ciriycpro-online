# CLAUDE.md — сайт аутстаффинга рабочих и мастеров (ИП Таиров)

## Что это
Корпоративный многостраничный сайт поставщика рабочих, мастеров и бригад на объекты Москвы и МО.
Главная — длинный лендинг с полной воронкой. Разделы — полноценные страницы, в которых можно «утонуть».
Каждая внутренняя страница = мини-лендинг: боль → решение → доказательство → условия → заявка.

Источник правды по контенту: `docs/corpus.md` (полный корпус, 18 разделов) и `docs/summary.md`.
Если что-то в коде расходится с корпусом — прав корпус. Не выдумывать услуги, цены, кейсы сверх корпуса.

## Стек
- **Astro** (статический вывод), React-острова только там, где нужен интерактив: форма заявки, калькулятор смены/бригады.
- Контент — Markdown/JSON в `src/content/` (Astro Content Collections): `services/` (14), `cases/` (5), `audiences/` (4), `faq.json`, `prices.json`, `company.json`.
- Стили — vanilla CSS с custom properties (без Tailwind), один `global.css` + scoped-стили компонентов.
- Деплой — GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`). Домен — из пула Артёма (уточнить при старте).
- Форма → POST на лёгкий эндпоинт (Cloudflare Worker / Cloud Run) → Telegram Bot API (чат Таирова) + строка в Google Sheets. Honeypot + rate-limit. Скрытые поля: URL страницы, UTM, timestamp.

## Дизайн-бриф
- Регистр: промышленный B2B. Прямой, деловой. Никакого «уюта», стоковых улыбок, эмодзи.
- Палитра: графит `#23272B` (основной текст/хедер), оранжевый `#F47B20` (акцент, CTA), белый, светло-серый `#F3F5F7` (фоны секций), зелёный `#2E7D32` (успех формы).
- Шрифты: Manrope 700/800 (заголовки), Inter 400/500/600 (текст). Google Fonts, `font-display: swap`, fallback system-ui.
- Сетка 12 колонок, контейнер 1200px, карточки с мягкой тенью, крупные цифры, воздух. Иконки — Lucide, монохром.
- Фото: пока нет — нейтральные фоновые заглушки без лиц (CSS-градиент/паттерн), слоты под «до/после» в кейсах.
- Мобилка первична: ≥55% трафика с телефона. На мобильном — закреплённая нижняя панель «WhatsApp · Позвонить · Заявка».
- Референсы (что нравится заказчику — заполнить после его выбора): см. `docs/references.md`.

## Правила качества
- Lighthouse: Performance ≥ 90, SEO 100, Accessibility ≥ 90 на мобильном.
- Изображения WebP/AVIF, `loading="lazy"`, явные width/height. Никаких тяжёлых слайдеров.
- Семантика: один H1 на страницу, логичная H2/H3, `<main>`, `<nav>`, `<article>`, хлебные крошки.
- Все цены в HTML-таблицах (не картинки). Все контакты — кликабельные `tel:`, `https://wa.me/`, `https://t.me/`.

## SEO
- Уникальные `title` (≤60 зн.), `description` (≤155 зн.), canonical, Open Graph на каждой странице.
- JSON-LD: `LocalBusiness` (главная, контакты), `Service` + `Offer` с ценами (14 страниц), `FAQPage` (FAQ и блоки FAQ услуг), `Article` (блог), `BreadcrumbList` везде.
- `sitemap.xml` (с lastmod), `robots.txt`.
- Внутренняя перелинковка строго по матрице §3.3 корпуса.

## LLM-friendly (чтобы LLM находили и цитировали)
- `/llms.txt` в корне: кто мы, что делаем, ссылки на ключевые страницы с 1-строчными описаниями; `/llms-full.txt` — весь контент услуг и FAQ в plain text.
- Markdown-зеркало каждой страницы: `/uslugi/demontazh.md` и т.д. (Astro endpoint, отдаёт тот же контент без вёрстки).
- `robots.txt` явно разрешает: GPTBot, ClaudeBot, anthropic-ai, PerplexityBot, Google-Extended, YandexBot, Bingbot.
- Первый абзац каждой страницы — прямой ответ на запрос с цифрами (цена «от», бригада, срок, зона). Без воды.
- FAQ — короткие точные ответы (1–2 предложения), размечены FAQPage.
- Данные о компании (название, телефон, зона, часы) — одинаковые везде (NAP-консистентность), источник — `company.json`.
